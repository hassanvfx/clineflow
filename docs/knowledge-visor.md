# Knowledge Visor

The ClineFlow Knowledge Visor is an optional, local report generated by the ClineFlow MCP server. It reads the project's OKF knowledge and Git facts from an explicit project root. It never writes canonical knowledge, starts a web server, opens a browser, or makes browser-time requests.

## Open the dashboard

Ask an MCP-enabled coding agent:

```text
Please show me the ClineFlow dashboard.
```

The agent calls `clineflow_dashboard_generate` with the absolute project root. The server renders a self-contained report without opening it. Grounded, source-linked observations may be supplied as insights; unsupported delivery estimates are omitted.

## Ownership and output

The global server package owns its renderer, pinned dependencies, and visual assets. Project-specific state is always confined to:

| Location | Purpose |
| --- | --- |
| `.clineflow-mcp/dashboard/runs/<run-id>/` | Complete self-contained reports. |
| `.clineflow-mcp/dashboard/` | Retention and dashboard settings. |
| `.clineflow-mcp/exports/<export-id>/` | Explicitly authorized sanitized exports. |
| `.clineflow-mcp/operations/` | Operation receipts and recovery diagnostics. |

Reports contain `index.html`, normalized facts, observations, a presentation model, and provenance. The MCP-managed `/.clineflow-mcp/` exclusion is marker-delimited in `.git/info/exclude`; it does not modify `.gitignore` or `knowledge/`.

## Retention and export

`clineflow_dashboard_settings` reads or changes report retention. `clineflow_dashboard_export` requires explicit authorization and creates a sanitized export below `.clineflow-mcp/exports/`. Retention applies only after a successful report and leaves malformed directories untouched.

## Privacy and removal

There are no analytics, remote iframes, browser-time API calls, credentials, or background dashboard process. ClineFlow removal leaves `.clineflow-mcp/` and old `knowledge/dashboard/` reports intact. Global MCP removal affects only its own runtime and exact, credential-free client configuration entries.
