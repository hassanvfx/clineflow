The dashboard groups legacy journals by an explicit valid tag where schema-3 topic metadata is absent.

# Decisions

- Legacy journal content is not an automatic semantic migration. Only frontmatter metadata becomes provenance and chronology; structured project facts require a future explicit record.
- The importer is dependency-free in standard installations. It uses PyYAML when present and a narrowly scoped fallback parser for the historical header fields when it is not.
- Re-running the updater adds no duplicate import records because the source path is recorded as an immutable import key.
