# Goal

Make captured dashboard facts and scientific-brochure report identity truthful
before the larger four-tab presentation implementation.

# Task Contract

- Intended outcome: Add a source-bound report-identity model, fixture provenance,
  latest captured commit, and truthful additive-ledger handling to M0 facts.
- Observable success criteria: The frozen Ad Crush fixture retains its own identity
  and baseline rather than host Git metadata; generated facts expose deterministic
  project/coverage/commit/condition fields; tests prove missing/unknown states.
- Constraints and non-goals: Preserve local read-only/offline report behavior,
  canonical source formats, source ownership, existing dirty worktree changes, and
  CLI entry points. No visualization dependency, public sharing, PDF overhaul, or
  full UI redesign in this slice.
- Open questions and assumptions: A dedicated recorded project title is optional;
  repository basename is the deterministic fallback. The current fixture lacks
  captured commits, so latest commit may be its recorded baseline and must say so.

# Execution Boundaries

- Authorized scope: Optional dashboard collector/presentation contracts, frozen
  fixture importer/data, dashboard tests and this knowledge stream. Exclude sibling
  project sources, canonical schemas, external dependencies, and publication.
- Affected interfaces: Generated snapshot/presentation JSON gains additive fields;
  report consumers remain backward compatible. Release manifest refresh may be
  required when optional installed payload changes.
- Escalate before adding a dependency, a canonical knowledge format, networked
  operation, or public artifact. No delegation; current agent integrates proof.

# Handoff Topology

- Selection: single handoff. This is one cohesive collection/fixture/presentation
  data-contract slice with one consumer (M1/M2).
- Entry: current optional dashboard and frozen fixture. Output: documented facts
  fields and deterministic tests. Local proof: fixture generation/observation/render,
  field assertions, existing dashboard boundary suite, validators and whitespace.
- Rollback: retain the prior facts contract if output no longer preserves source
  hash, offline generation, or fixture provenance. Current agent is integrator.

# Decisions

- Identity records captured source kind, project title/description, report creation,
  coverage, baseline, latest captured commit and condition separately.
- Unavailable values are explicit. A baseline commit is not called a latest commit.
- Project title uses a fixture field when present, then repository basename; it is
  not generated by observations or selected activity.
