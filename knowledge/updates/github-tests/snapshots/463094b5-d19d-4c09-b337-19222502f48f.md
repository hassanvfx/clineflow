# Work Log

## 2026-09-07 - Diagnosed clean-checkout failures

GitHub Actions run `34074592596` failed in both jobs. The Windows installer
reported a checksum mismatch for `.clineflow/core-requirements.lock`, which
is a shipped text payload omitted from the existing LF attribute list. The
Linux job completed its fixture matrices, then root OKF validation failed
because ClineFlow 3 ignores generated `knowledge/clineflow_*.yml` projections
and a clean checkout has not rebuilt them.

## 2026-09-07 - Implemented and verified the repair

Added the missing LF attribute for lockfiles, rebuilt projections immediately
before root OKF validation, and made release validation reject a certification
entrypoint that omits that rebuild. Added regression assertions for both
safeguards, updated payload checksums, and released `2026.09.07.0` without a
migration.
