# ClineFlow 3 knowledge sources

Create work with `./.clineflow/bin/knowledge journal new`, publish an immutable
record with `knowledge record`, and run `knowledge sync` before reading the
five familiar ledger views. The generated ledgers, update log, and journal/topic
indexes stay local; the committed sources are journals and `knowledge/updates/`.
